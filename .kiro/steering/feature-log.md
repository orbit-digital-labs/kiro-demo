อ่านไฟล์ `index.html` และ `app.js` ทั้งไฟล์ แล้วสรุป 'ฟีเจอร์ที่ใช้งานได้จริงตอนนี้' เป็นภาษาไทย สำหรับโชว์ลูกค้าท้าย workshop:

- ไล่จากสิ่งที่ผู้ใช้เห็นและกดได้จริงบนหน้าเว็บ: ยอดสรุป ฟอร์มเพิ่ม/แก้ไข ลิสต์รายการที่แบ่งกลุ่มรายเดือน ตัวเลือกเดือน กราฟรายจ่ายตามหมวด การบันทึกลง localStorage ข้อมูลตัวอย่างย้อนหลัง 3 เดือน โหมดมืด และฟีเจอร์ที่เพิ่มระหว่าง session
- เช็คจาก `app.js` ด้วยว่าฟีเจอร์นั้นมี event listener และฟังก์ชัน render ผูกครบจริง ไม่ใช่มีแค่ปุ่มใน HTML
- หนึ่งฟีเจอร์ = หนึ่ง bullet: ชื่อฟีเจอร์สั้น + คำอธิบายไม่เกิน 1 บรรทัด
- เรียงจากฟีเจอร์หลักของแอพ ไปหาฟีเจอร์ที่เพิ่มระหว่าง session
- ห้ามแก้โค้ด ห้ามเสนอฟีเจอร์ใหม่ นี่คือรายงานสรุปผลงานเท่านั้น
- ปิดท้ายบรรทัดเดียวตัวหนา: 'รวม N ฟีเจอร์ สร้างสดใน session เดียว'
